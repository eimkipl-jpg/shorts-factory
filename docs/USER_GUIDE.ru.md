# Shorts Factory

Автоматический монтаж вертикальных видео (Shorts) на VPS: Telegram → очередь → озвучка/субтитры/монтаж → Google Drive.
Загрузка на YouTube - вручную (забираете готовый `final.mp4` и `metadata.json` с Диска).

## Как это работает

```
Telegram-бот ──► tasks/task_N/{input_audio, metadata.json} ──► очередь (SQLite)
                                                                    │
   Банк фонов (Pexels/Pixabay, cron) ─────────────► Ядро сборки (worker)
                                                    озвучка* → Whisper → .ass → ffmpeg 9:16
                                                                    │
                                     rclone move ◄──────────────────┘
                                          │
                          Google Drive: ShortsFactory/<канал>/task_N/{final.mp4, metadata.json}
```
\* озвучка (edge-tts) включается, только если вы прислали текст вместо аудио.

## Установка

```bash
sudo bash install.sh         # ставит ffmpeg, rclone, venv, systemd-сервисы, cron
nano .env                    # BOT_TOKEN, ALLOWED_USER_IDS, ключи Pexels/Pixabay, каналы
sudo bash install.sh         # повторно: запустит сервисы
rclone config                # remote для Google Drive; имя = RCLONE_REMOTE из .env
venv/bin/python -m backgrounds.refill   # первое наполнение банка фонов
```

Бесплатные API-ключи: https://www.pexels.com/api/ и https://pixabay.com/api/docs/

## Использование

- `/channel channel2` - выбрать канал, для которого делаете ролик (список каналов в `.env`, `CHANNELS`).
- Пришлите аудио с подписью: `Заголовок | Описание | #тег1 #тег2`
- Или текст: первая строка - такая же подпись, ниже - текст для озвучки.
- Тег, совпадающий с названием темы фонов (например `#gameplay`), выбирает папку фонов; иначе фон случайный.

Бот отклоняет файлы, если: нет подписи в нужном формате, файл не аудио, длительность вне 3-90 с, файл больше 20 МБ.
Для больших файлов поднимите локальный Telegram Bot API server и укажите `TELEGRAM_API_URL`.

## Конструктор ролика (/new)

Шесть блоков на кнопках: 1 Видеоряд · 2 Речь · 3 Музыка (и звуковые эффекты) · 4 Субтитры · 5 Стиль · 6 Канал.

- **Пресеты** (💾) сохраняют все настройки под именем; **🎲 Сюрприз** собирает случайный вид ролика.
- **Речь**: голос выбирается кнопками (список `TTS_VOICES` в `.env`), скорость речи от -20% до +35%, кнопка «🎧 Прослушать».
- **Стиль**: монтаж (переходы, зум, цвет), компоновка (заполнить, размытый фон, сплит, рамка), скорость видео и эффекты,
  текст на экране (хук в начале, призыв в конце; оба могут быть случайными из списка канала, список правится кнопкой «Мои фразы»),
  постоянная подпись на всё видео (например, название снизу), полоска прогресса (линия, капсула, неон) с кнопками лайка и подписки
  в конце, логотип канала, вид и положение субтитров.
- **Звуковые эффекты**: свист на стыках клипов и удар в начале. Встроенные звуки синтезируются ffmpeg (`assets/sfx/`),
  свои кладите на Диск в `ShortsFactory/_clips/_sfx/<тег>/`.
- **Материалы**: «🔎 Найти в интернете» ищет клипы в Pexels и Pixabay (нужны `PEXELS_API_KEY` и `PIXABAY_API_KEY`),
  скачивает выбранное в тему и копирует на Диск; «➕ По ссылке» скачивает ваше видео в `_own` через yt-dlp.
  Источник и лицензия сохраняются в библиотеке (`/lib`, `/src <id> источник | лицензия`).
  Перед публикацией проверяйте актуальные условия Pexels License и Pixabay Content License.

Папка клипов на сервере зеркалится с Диска (`rclone sync`): всё, чего нет на Диске, при синхронизации удаляется.
Поэтому бот после каждой загрузки копирует файл на Диск; если видите предупреждение rclone, загрузите файл на Диск вручную.

## Названия для своих видео

Видео, скачанные с именем-ID YouTube (`0NhbnKSkGqM.mp4`), получают настоящее название командой `/names`
(или кнопкой «🏷 Названия моих видео» в `/lib`). Файлы при этом не переименовываются: название хранится в библиотеке.
Вручную: `/title <id> название`. Названия видны в выборе «Моё видео», в `/find` (поиск и по словам из названия) и в промте для нейросети.
Новые видео, скачанные кнопкой «➕ По ссылке», называются по заголовку сразу.

## Сценарий из JSON (/prompt)

Сценарий пишет нейросеть, бот только собирает. `/prompt` присылает промт, в который подставлены ваши темы клипов,
теги музыки и звуков, голоса и свои видео. Ответ нейросети (JSON) пришлите боту текстом или файлом `.json`:
бот проверит его, исправит опечатки в названиях тем и тегов, покажет сводку и замечания и после «🚀 Собрать» поставит в очередь.
Каждая сцена = одна фраза (озвучка) + свой клип, длина сцены равна длине озвучки. Схема полей описана в `core/scenario.py`.

## Истории (/story, «📖 Истории» в меню)

Формат «вопрос и история в комментарии»: сначала карточка поста с вопросом, затем карточка комментария; слова появляются
в момент, когда их произносит диктор (время слов - по Whisper, текущее слово подсвечено), длинная история листается
страницами по предложениям. Карточки своего дизайна, без логотипов и интерфейса чужих площадок.
Фон - залипательные видео из `_clips/_satisfying/` на Диске (подпапки = виды: `parkour`, `sand` и т. п.); добавляются
кнопками в режиме (видео до 20 МБ или по ссылке) или прямо на Диск + «🔄 С Диска».
Промт для нейросети (язык и жанр на выбор) просит придумать историю с нуля. Схема JSON - в `core/story.py`.
Оформление: светлая/тёмная карточка, «поверх видео» или «сверху карточка, снизу видео», подсветка слова, полоска прогресса,
голос и музыка.

## Умный монтаж (/smart, «🎞 Умный монтаж» в меню)

Ролик по сценарию: тема → сценарий со сценами → озвучка → кадры под смысл каждой фразы → ролик.
1. «📋 Промт для сценария» → язык → тема. Бот присылает промт; нейросеть возвращает JSON: у каждой сцены `text` (фраза для озвучки)
   и `visual.query` (что показать, 2-5 слов по-английски) плюс запасные `visual.alt`. Необязательно: `theme` (папка своей библиотеки),
   `own` (конкретное своё видео), `voice`, `music`, `channel`.
2. JSON присылается текстом или файлом `.json`; бот показывает сводку (сцены и запросы кадров) → «🚀 Собрать».
3. Сборка: озвучка одним проходом, время слов по Whisper; граница сцены - начало её первой фразы. Для каждой сцены клип ищется в своей
   библиотеке (теги, названия), потом на Pexels/Pixabay (скачанное сохраняется в библиотеку с тегами запроса и на Диск), потом по запасным
   запросам и теме. Длинные сцены режутся на куски до 6 с из разных клипов. Субтитры по словам озвучки.
   Клип берётся, только если слова запроса совпали с описанием или тегами ролика (не меньше половины, максимум по трём словам).
   Ролики без общих слов не скачиваются, теги запроса получают только подошедшие ролики. Нет подходящего кадра - сцена получает
   тёмный фон (с цифрой, если она есть) вместо случайного видео, а в замечаниях к ролику перечислены такие сцены.
4. Цифры и графики: у сцены можно задать `stat` - `{"kind":"number","value":"3.2%","label":"...","delta":"-0.5 п.п.","source":"BLS"}`
   (число растёт от нуля), `{"kind":"bars","items":[{"label":"2015","value":4},{"label":"2024","value":6.5,"text":"$6.5"}]}`
   (столбцы), `{"kind":"line","values":[1.4,7,6.5,3.4],"labels":["2021","2024"]}` (линия). Плашка лежит над субтитрами; `"full":true`
   делает карточку на весь кадр без видео. Без `source` бот предупредит: цифры надо проверять до публикации.
   Графика на весь кадр (`stat.full` или виды `list`, `compare`, `fact`) не требует видео: сцена получает цветной градиентный фон с
   плавающими кругами, поверх рисуется карточка. Промт просит нейросеть делать такими 60-80% сцен, а видео оставлять для крючка,
   пары сцен и призыва. Виды: `number`, `bars`, `line`, `compare` (две колонки VS), `list` (2-4 пункта по очереди), `fact` (крупная фраза
   с подсвеченным словом `accent`).
5. В metadata.json остаётся `smart_report`: какой клип и откуда взят для каждой сцены (library, stock, weak - слабое совпадение, card - фон)
   и тип цифры.

Сюжет «вопрос → ответ» (с патча 36). Ролик отвечает на один вопрос из первой фразы. В JSON поля `question`, `answer`, `punchline`
(две параллельные фразы), `flip` (финальный поворот) и `hero` (главный кадр темы: `{"type":"archive","query":"...","alt":[...]}`).
Такты сцен (`block`): hook (вопрос) → context → reveal («то есть не X, а Y») → escalate («причём») → reason («и причина довольно
простая») → main → punch → other → flip. Старые блоки hook/setup/main/climax/cta тоже принимаются. Сводка проверяет сюжет до монтажа:
вопрос в начале, связки между фразами, финал возвращается к вопросу, нет «подпишись», слов не больше, чем позволяет длина.
Крупный текст: `"emphasis": ["ключевое слово"]` у сцены (до трёх на ролик) - слова диктора появляются крупно по одному поверх
затемнённого кадра, ключевые слова - отдельной страницей цветом; субтитров в этот момент нет. Главный кадр - фон крупного текста и
карточек (тёмное оформление) и замена, когда точной картинки для сцены нет (сцена без `visual` сразу получает его). Палитра одна на
ролик. После вопроса, перед панчлайном и финалом озвучка держит паузу 0,35 с. Новые настройки: графика «минимум: 2-3 карточки»,
субтитры «спокойные, 2 строки», длина «60-75 с»; при обновлении сохранённые настройки переходят на графику «минимум», спокойные
субтитры, 45-60 с и живой темп вместо быстрого (остальное не меняется).

Чёткость (патч 37): картинку не растягивают больше чем в 1,35 раза. Маленькая горизонтальная (Pixabay отдаёт до 1280 px) идёт
во всю ширину кадра на размытой подложке из неё же, узкая вертикальная (уже 900 px) - карточкой; архив Wikimedia берётся до 2560 px.
Масштабирование lanczos с лёгкой резкостью. Из стоковых видео при равном смысле берётся то, что в вертикальном кадре чётче (4K или
вертикальное, а не 1920x1080 с обрезкой и растяжением почти вдвое).

Сценарий: промт просит нейросеть сначала сформулировать главную мысль (`idea`) и написать текст целиком (`script`) как одну историю
с причинно-следственной цепочкой, где кульминация отвечает на вопрос крючка, и только потом резать его на сцены и подбирать картинку.
Под сводкой есть кнопка «✍️ Промт для доработки»: она даёт промт-редактор с вашим JSON, нейросеть возвращает исправленный сценарий.
Голос: весь текст озвучивается одним абзацем, длинные паузы Edge между фразами сжимаются до 0,13-0,32 с («🗣 Темп речи» в настройках).
Субтитры умного монтажа рисуются самим режимом: текст из сценария, текущее слово подсвечено, шрифт Fira Sans (лежит в патче,
ставится в ~/.fonts при первой сборке; лицензия SIL OFL, core/FONTS_OFL.txt). Со стоков Pixabay берётся только живая съёмка, без мультфильмов.

Картинки сцены (`visual.type`): `video` - живое стоковое видео; `photo` - стоковое фото Pixabay; `illustration` - рисованная
иллюстрация Pixabay; `archive` - настоящие исторические фото Wikimedia Commons (без ключа, только свободные лицензии; автор и
лицензия сами дописываются в описание ролика). Картинка оживает: наезд, отъезд или панорама, горизонтальная лежит карточкой на
размытой подложке. Если картинка не нашлась - бот пробует фото, затем видео, затем цветной фон.
Карточки с иконками (шрифт Phosphor, 1500+ иконок, MIT): `flow` - цепочка причин со стрелками, `icons` - 1-3 крупные иконки с
подписями, у `fact`, `number` и пунктов `list` - необязательное поле `icon` (простое английское слово: bread, bank, sword, printer).
Промт строит сценарий как историю: исследование фактов, один угол, форма истории, 5 вариантов крючка, петля и поворот, финал-ответ,
самооценка по рубрике; в сводке бот предупреждает об однообразии (больше двух одинаковых карточек или много карточек подряд).

Настройки (⚙️) разбиты на разделы:
- 🎙 Голос и звук: голос, темп речи, музыка и её громкость;
- 🖼 Картинки и источники: подача горизонтальных картинок (на весь кадр с панорамой или карточкой на размытом фоне), строгий подбор
  (картинка берётся, только если описание совпало с запросом, именами и годами; иначе - крупная иконка по смыслу), какие источники
  разрешены (стоковое видео, фото, иллюстрации, архив Wikimedia), поиск в интернете вообще;
- 🎨 Графика и субтитры: доля карточек на весь кадр, оформление (тёмное цветное, светлое, чёрное), субтитры (подсветка слова,
  жёлтые, белые, выключены), их размер, место и регистр;
- 📝 Сценарий: длина ролика (20-30, 30-45, 45-60 с) и подача (научпоп, история другу, с юмором, драматично, экспертно) - идут в промт;
- ✨ Монтаж: переходы между сценами (резкие склейки, чистые, плавные, динамичные, документальные, кино, хайп).
«↩ Сбросить по умолчанию» возвращает всё, кроме голоса и музыки.

Графика (⚙️ Настройки → 🎨): доля сцен, которые бот рисует сам вместо видео со стоков: нет, мало 20-30%, средне 40-50%, много 60-80%. Настройка идёт в промт для нейросети и проверяется при сборке (при «нет» карточки на весь кадр пропускаются).

Голос: бесплатные Edge-голоса или ElevenLabs. Для ElevenLabs в `.env`: `ELEVENLABS_API_KEY=...`, `ELEVENLABS_VOICES=Диктор:voice_id,Второй:voice_id2`
(модель - `ELEVENLABS_MODEL`, по умолчанию `eleven_multilingual_v2`). Голоса из списка выбираются в «⚙️ Настройки» как «ElevenLabs · Диктор».
Проверка кадров по смыслу: если в `.env` задан `ANTHROPIC_API_KEY` (console.anthropic.com), Claude смотрит на превью найденных роликов
и кадры из библиотеки и оценивает их от 0 до 10 (берутся от 6; снижает оценку за чужие страны, вывески и водяные знаки).
Отправляются только маленькие превью и фраза сцены, это доли цента на ролик (`VISION_MODEL`, по умолчанию `claude-haiku-4-5-20251001`).
Без ключа подбор идёт по тегам и описаниям, он заметно хуже. Субтитры берутся из текста сценария, время слов - из Whisper.
Ключи Pexels/Pixabay (`PEXELS_API_KEY`, `PIXABAY_API_KEY`) нужны для поиска на стоках; без них берётся только своя библиотека.

### Исторические карты (патч 38)
Сцена с полем `map` вместо картинки: тёмная плоская карта с границами государств на любой год от 3400 до н. э. до 2024,
подсветка государств, метки городов, стрелки, крупный год сверху. Если лет несколько, границы меняются прямо в кадре,
а год «прокручивается». Камера медленно наезжает, подписи едут вместе с ней.
- Настройка: ⚙️ → «🎨 Графика и субтитры» → «🗺 Карты»: «по сценарию» (нейросеть ставит карту, где важно «где») или «выключены».
- Формат: `"map": {"years": [1850, 1890], "title": "Индокитай", "highlight": [{"at": "Бангкок", "label": "Сиам"}], "pins": ["Бангкок"], "arrows": [{"from": "Париж", "to": "Ханой"}], "cues": ["британцы"]}`.
  `at` - современный город или страна, бот сам находит, какому государству точка принадлежала в каждый год. `label` - подпись
  (строка или `{год: подпись}`), без неё - название из Викидаты. `cues` - слова из текста сцены, на которых меняется год.
- Проверка до сборки: `/map 1850 1910 Бангкок, Ханой` присылает кадр карты на каждый год.
- Данные: Cliopatria v0.2.1 (Seshat Global History Databank, CC BY 4.0) и Natural Earth (public domain), лежат в `core/mapdata`
  (~11 МБ). Русские названия государств подтягиваются из Викидаты и кэшируются в `<ROOT>/mapcache`.
- Лицензия CC BY: строка с автором данных карт сама добавляется в описание ролика - не удаляйте её.

## Задачи (/plan, «📋 Задачник» в меню)

Недельный план по каналам. Меню - список каналов; канал открывает задачи на выбранный день (◀ ▶ - соседние дни, «Сегодня»).
- Задача: просто напишите её сообщением, пока открыт канал. Одно сообщение = одна задача, абзацы сохраняются; несколько задач
  разделяйте строкой `---`. В первой строке понимаются время (`14.30` или `14:30`), срок (`завтра`, `12.10`, `в пятницу`),
  повтор (`каждый день`, `по будням`, `по пн ср пт`) и `#канал`. Без срока задача ставится на открытый день.
- «☑ N» отмечает выполненной (остаётся в списке, «↩ N» возвращает), «⚙ N» открывает карточку: текст, время, день, перенос на завтра,
  копия на другой день, повтор, другой канал, удалить.
- «🗓 Неделя»: обзор недели канала и «📥 План на неделю» - весь план одним сообщением:
  строка с днём (`пн`, `вторник`, `14.10`) начинает день, каждая следующая строка - задача (`10.00 Снять мем`), строка `+ ...`
  дополняет предыдущую задачу, строка `#Канал` переключает канал. «📑 Копия на следующую» переносит задачи недели на следующую.
- Время у задачи: за 2 часа до него приходит сообщение «⏰ время · задача · канал» с кнопками «Готово» и «Завтра».
- «🔁 Повторы»: каждое утро из повтора создаётся задача на сегодня (со временем, если оно указано); «🎬 Видео»: готовые ролики
  из очереди (или `/vid 63`) попадают в блок «На загрузку».
- Утренний отчёт о просроченном и сегодняшнем в 08:00 (`/report` - вручную). Дни, время, напоминания и отчёт считаются по часовому поясу
  из «⚙️ Отчёт и время» (по умолчанию Asia/Bangkok, можно Europe/Moscow или UTC).

## Каналы

Новый канал создаётся в «⚙️ Профиль» → «📺 Канал» → «➕ Новый канал» (или в банке идей). Бот сразу создаёт папки на сервере и на Диске
(`ShortsFactory/<канал>` для готовых роликов, `_ideas/<канал>`, `_projects/<канал>`), выбирает канал и показывает его везде:
конструктор, профиль, идеи, истории, задачник. Список хранится в `channels.json` и дополняет `CHANNELS` из `.env`.

## Что лежит на Google Drive

`ShortsFactory/<канал>/task_N/final.mp4` и `metadata.json` (заголовок, описание, теги - копируете в YouTube Studio).
Локальная папка задачи удаляется с VPS после успешной выгрузки. Ночной cron (`transport/cleanup.py`) добирает остатки.

## Требования к серверу

Минимум 2 vCPU, 4 ГБ RAM, 40 ГБ диска. Задачи обрабатываются по одной, поэтому этого хватает.
Модель Whisper `base` заметно точнее `tiny` на русском; если сервер слабый - поставьте `WHISPER_MODEL=tiny`.

## Выбор роликов и нарезчик

- **Выбор роликов вручную.** В `/new` → 1️⃣ Видеоряд (нарезка из клипов или «Моё видео») → «🎯 Выбрать ролики»: отметьте нужные
  клипы или свои видео, они склеятся ровно в том порядке, в каком выбраны. «🧹 Сбросить выбор» возвращает случайную нарезку по теме.
- **Нарезчик** (`/cut` или 📚 Библиотека → «✂️ Нарезка видео»): выберите своё видео и режим.
  «По переходам» делит по сменам кадра (короткие фрагменты склеиваются, длинные делятся), «Интересные моменты» оставляет лучшие
  по громкости звука и движению. Фрагменты сохраняются со звуком в `clips/<тема>/`, попадают в библиотеку и на Диск
  (иначе синхронизация с Диском их удалила бы). Работает в воркере, по окончании бот пришлёт сообщение.

### Бот для креаторов (патч 39)
Второй экземпляр фабрики для чужих пользователей: отдельный токен BotFather, свой каталог данных (`<FACTORY_ROOT>_creator`), своя база, свои сервисы
`creator-gateway` и `creator-worker`. Основной бот не меняется. Установка: `python3 creator_setup.py` (токен, ваш ID, пакеты цен).
- **Free starter**: `FREE_VIDEOS` (3) демо-роликов с водяным знаком `WATERMARK`; дальше кредиты. Кредит = ролик; списывается при постановке в очередь, возвращается, если сборка не удалась.
- **Оплата**: Telegram Stars (`CREATOR_PACKS="10:150,30:400"` = роликов:звёзд). Платёж идемпотентен по id платежа.
- **Лимиты**: `DAILY_LIMIT` в сутки, `MAX_QUEUED` в очереди у одного, `MAX_QUEUE_TOTAL` всего; «вы N-й в очереди».
- **Изоляция**: Google Drive владельца недоступен (`DRIVE_ENABLED=0`, `RCLONE_CONFIG` указывает в никуда), готовое видео уходит в чат Bot API (до 50 МБ, при необходимости пережимается) и удаляется с сервера.
- **Общий замок рендера** (`RENDER_LOCK`): воркеры двух ботов собирают по очереди, приоритет равный.
- **Админ** (`ADMIN_IDS`): без лимитов, `/grant <id> <n>`, `/ban`, `/unban`, `/stats`.
- Условия: `/terms` берёт текст из `<каталог>/terms.txt`, если файл есть.

#### Защита бота для креаторов (патч 40)
- **Изоляция процессов**: юниты запускаются с `ProtectSystem=strict`, `NoNewPrivileges`, недоступны токен rclone, основной `.env` и `~/.ssh`; память ограничена (`MemoryMax`). Если с изоляцией сервис не стартует, `creator_setup.py` сам ставит обычный режим и пишет об этом.
- **Бесплатный старт**: `FREE_DAILY_TOTAL` демо в сутки на весь бот, `FREE_QUEUE_MAX` бесплатных мест в очереди, платные ролики идут вперёд; необязательная подписка на `REQUIRE_CHANNEL`.
- **Рендер**: ролик до `CREATOR_MAX_SECONDS` (75 с), предохранитель `TASK_TIMEOUT` (1200 с, без повтора, кредит возвращается).
- **Антиспам**: не больше 15 действий за 10 с на человека, пауза 5 с между сценариями, разбор сценария вне основного цикла бота.
- **Деньги**: `/refund <charge_id>` возвращает Stars и снимает кредиты; ежедневная копия базы (`python -m common.backup`, 7 копий в `<каталог>/backups`).
- **Данные**: `/delete_me`; журнал заголовков роликов хранится 30 дней; стоп-слова - файл `<каталог>/blocklist.txt` (по слову в строке).

#### Бот для креаторов: этап 1 (патч 42)
- **Бесплатный режим** `CREATOR_FREE_MODE=1` (по умолчанию): без кредитов и водяного знака; лимиты в сутки - `DAILY_LIMIT` роликов, `DL_DAILY` скачиваний, `CUT_DAILY` нарезок.
- **Новое меню**: умный монтаж, нарезка, скачивание, настройки, публикация и метрики, инструкция; разделы следующих этапов помечены «скоро».
- **Скачивание** (`core/fetch.py`, yt-dlp): только публичные http(s)-адреса, универсальный извлекатель выключен; до `DL_MAX_MINUTES` минут; видео до 50 МБ (тяжелее пережимается).
- **Нарезка** (`core/creatortasks.py` + `core/cutter.py`, параметр `out_dir`): по ссылке или файлом (до 20 МБ через Bot API), до `CUT_MAX_MINUTES` минут; фрагменты приходят альбомом (до 10) или zip-архивами; в общую библиотеку клипов ничего не попадает.
- **Метрики по ссылке** без API (yt-dlp): просмотры, лайки, комментарии, ER, охват к подписчикам. **Автопубликация** - «в разработке».
- **Подробные настройки**: каждая настройка открывается экраном с вариантами и пояснением, «📖 Гайд» по разделу, выбор голоса с прослушиванием, выбор музыки.
- **Инструкции-схемы** (`core/guide.py`): PNG по шагам, кэш в `<каталог>/guides`.
- yt-dlp ставится командой `python3 creator_setup.py --deps` (тот же Python, что у сервисов).

#### ReelsEditor (патч 43)
Монтаж сырой «говорящей головы» без озвучки и аватаров (`core/reels.py`, задача `reels` в воркере, раздел в `gateway/creatorui.py`):
Whisper с таймингами слов (подсказка с «э-э», чтобы паразиты попадали в текст) → вырезаются паузы длиннее порога, паразиты
(«э», «эм», в строгом режиме «типа», «короче», «как бы»), повторы подряд и фальстарты → куски кодируются отдельно ровно по
кадрам 30 к/с, звук собирается из исходника по тем же границам с затуханиями 12 мс (рассинхрона нет) → зумы на акцентах
(самые громкие содержательные слова) и через склейку → вставки со стоков по ключевым словам (поиск Pexels/Pixabay на языке
речи) → субтитры оформлением умного монтажа → шумоподавление и громкость −14 LUFS. Лимиты: `REELS_DAILY` (5) в сутки,
`REELS_MAX_MINUTES` (5) длина исходника. Видео принимается файлом (до 20 МБ через Bot API) или ссылкой (Google Диск, Яндекс Диск, YouTube и др.).

#### Форматы, бренд-профиль, UGC-реклама, разбор референса (патч 44)
- **Форматы** (`core/formats.py`): 9:16, 4:5, 1:1, 16:9. ReelsEditor монтирует сразу в формате (субтитры на холсте 1080×N без искажений);
  ролик умного монтажа переводится в формат в конце (на размытом фоне или обрезкой; 16:9 - всегда на фоне).
- **Бренд-профиль** (`core/brand.py`): название, цвет (подсветка субтитров и плашка призыва), логотип в верхнем углу
  (`<каталог>/brands/<id>/logo.png`), призыв в последние 3 с, хэштеги к описанию. Логотип и призыв накладываются тем же проходом, что и формат.
- **UGC-реклама** (`core/refs.py`): описание товара → промт на 2/3/5 вариантов с разными хуками (`{"variants": [...]}`) →
  каждый вариант проверяется как сценарий умного монтажа → «Собрать все» или один.
- **Разбор референса**: задача `ref` (лимит `REF_DAILY`, до `REF_MAX_MINUTES`): планы и склейки, темп речи, хук первых 3 с и его тип,
  призыв, раскадровка, текст → кнопка «Сделать похожий»: промт умного монтажа со структурой референса на теме пользователя.

#### Исправления по тестам (патч 46)
- Схемы-инструкции и логотип бренда требуют Pillow: ставится `creator_setup.py --deps` (вместе с yt-dlp), добавлен в requirements.
- Скачивание: ролики, у которых площадка не сообщает длину (часто Instagram), больше не отбрасываются как «длиннее N минут».
- Поддержка: `/support` без текста ждёт следующее сообщение и пересылает админу; админ отвечает `/reply <id> текст`; кнопка «🆘 Поддержка» в инструкциях.
- ReelsEditor: вставки ищутся по английскому переводу речи (Whisper task=translate) механизмом подбора умного монтажа;
  слово за словом, только уверенное совпадение с описанием ролика - иначе вставки нет.
- Умный монтаж: блиц из 4 шагов перед промтом (тема → главная мысль → обязательные факты → форма рассказа), правило «держись темы автора»;
  длина «90-120 с», в боте для креаторов до 120 с (`--deps` переписывает старое CREATOR_MAX_SECONDS=75).
- Настоящая активность вместо «очереди для вида»: «за сутки бот сделал N задач» и сообщение «ваша очередь подошла».
- Большие файлы: `creator_bigfiles.py` поднимает свой сервер Telegram Bot API (Docker `aiogram/telegram-bot-api`, локальный режим) только
  для бота креаторов - приём и отправка до 2 ГБ; `--off` возвращает облачный API, `--check` проверяет.

#### Живой текст и разнообразные кадры (патч 47, оба бота)
- Промт без шаблонов: убраны обязательные «и причина довольно простая», «то есть не X, а Y», зеркальный панчлайн и финал «так что да… не факт»;
  блок «Голос - как живой человек», расширенный список запрещённых оборотов (RU/EN), новый пример. Подача «как блогер» - по умолчанию
  (сохранённая «научпоп» переводится на неё, остальные настройки не трогаются).
- Проверка сценария: предупреждение о шаблонных фразах и одинаковых запросах кадров; кнопка «🗣 Сделать текст живее» - промт-редактор,
  который переписывает только тексты сцен.
- Кадры: главный кадр - не больше двух раз за ролик и не подряд, размытый фон из него - только у первой сцены; если точного кадра нет -
  упрощённый запрос (фото, видео, иллюстрация), затем иконка по смыслу.
- Новые источники: фото Pexels (тот же ключ), Openverse (CC0/PDM/CC BY/CC BY-SA, автор в описании), NASA (космос, общественное достояние);
  видео Pexels - и горизонтальные, если вертикальных мало.
